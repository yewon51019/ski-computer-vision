# 스키 주행 영상 자세 코칭 · 제품 요구사항

초안 0.3 · 2026-11-14 · MVP 범위와 시연 절차는 [mvp.md](mvp.md) 참조

## 사용자와 목표

스키어가 주행을 마친 뒤 영상 하나를 올려 어느 턴에서 어떤 동작을 바꿔 볼지 확인한다. 사용자가 관절을 클릭하거나 턴 시작점을 지정하지 않아도 결과를 생성한다. 주 사용자의 숙련도는 미정이다.

첫 촬영 조건은 슬로프 아래쪽에 서 있는 촬영자가 내려오는 스키어를 향해 카메라 방향을 유지하는 것이다. 손떨림은 정상 입력에 포함한다. 추적 촬영은 후속 지원 대상으로 두고, 두 방식에서 재사용할 수 있는 측정과 표시 기준을 유지한다.

## 사용 흐름

1. 사용자가 주행 영상을 선택한다. 앱은 지원 여부와 분석 상태를 표시한다.
2. 사용자는 결과 영상에서 스키어 기준 좌우 다리와 시점별 굽힘량을 확인한다.
3. 타임라인에서 숏턴 추정 구간을 선택하고, 구간 안의 턴 전환 표시와 턴별 소요 시간을 확인한다.
4. 코칭 문구를 선택하면 근거 장면으로 이동한다. 무엇을 관찰했고 다음 주행의 어느 시점에 무엇을 바꿔 볼지 읽을 수 있다.

## 기능 요구사항과 수용 기준

| ID | 요구사항 | 시연에서 확인할 동작 |
|---|---|---|
| FR-01 | 영상 한 편으로 분석 시작 | 관절·턴 수동 입력 없이 결과 재생까지 진행한다. 읽을 수 없는 영상에는 실패 사유를 표시한다. |
| FR-02 | 좌우 무릎 굽힘을 각 다리별로 표시 | 화면의 골반·무릎·발목 세 점으로 구한 내각을 180°에서 뺀 값을 표시한다. 단위와 ‘화면상 추정’임을 표시하고, 가려진 쪽은 해당 시점의 수치를 비운다. |
| FR-03 | 손떨림과 스키어의 방향 전환 구분 | 같은 주행의 원본과 인위적으로 화면을 흔든 사본을 비교한다. 손떨림 때문에 새 턴이나 교정 문구가 생겼는지 확인한다. 판별에 필요한 근거가 사라진 구간은 보류한다. |
| FR-04 | 연속 숏턴 구간 검출 | 구간의 시작·끝과 개별 턴 전환을 구별해 표시한다. 숏턴이 없는 비교 영상에서도 오검출을 확인한다. 무릎 굽힘을 측정할 수 있어도 턴 종류가 모호하면 숏턴 판정을 보류한다. |
| FR-05 | 리듬 표시 | 이웃한 전환 시각의 차이를 초 단위로 표시한다. 시작·끝이 잘렸거나 전환을 놓친 구간은 리듬 비교에서 제외한다. |
| FR-06 | 턴별 행동 지침 | 검토된 기준을 충족하는 장면에서 턴 구간, 관찰 근거, 바꿔 볼 동작을 함께 표시한다. 문구를 누르면 해당 구간을 다시 재생한다. |
| FR-07 | 턴별 전신 자세 코칭 | 무릎, 머리·상체의 전후 위치, 폴을 든 양팔의 손 높이·팔꿈치 굽힘·위팔 벌림·양손 너비를 항목별로 평가한다. 관찰 가능한 항목은 계속 표시하고 나머지는 보류 사유를 표시한다. |
| FR-08 | 전신 관절선 표시 (2026-11-17 추가) | 원본 영상 위에 다리만이 아니라 머리·어깨·양팔·몸통·허리와 스키·폴까지 관절선을 겹쳐 그린다. 스키어 기준 왼쪽·오른쪽을 색으로 구분하고, 모델이 확실히 찾지 못한 점에 닿는 선은 흐리게 그린다. 1단계는 몸 관절(MoveNet 17점), 2단계는 스키·폴 끝점을 포함한 EPFL 24점이다. |

## 코칭 판정 원칙

관절 추정과 동작 판정을 분리한다. 관절을 찾는 모델이나 라이브러리는 기술설계에서 정한다. 각도·시간을 해석하는 규칙에는 적용 가능한 촬영 시점, 턴 단계, 비교할 다리, 근거가 되는 시범 구간, 판정 보류 조건이 있어야 한다.

- **무릎 굽힘**이 첫 코칭 대상이다. 같은 촬영 시점·턴 단계의 검토된 기준과 비교하고 차이가 연속적으로 관찰될 때 문구를 표시한다. 예시 문안은 “표시한 턴의 진입 구간에서 무릎 굽힘이 기준보다 작게 관찰됐어요. 다음 주행에서는 이 구간에서 무릎을 조금 더 굽혀 보세요.” 실제 적용 기준과 지속시간은 미정이다.
- **머리·상체의 전후 위치**는 몸이 진행 방향 뒤쪽으로 빠지는 동작을 다룬다. 비스듬히 지나가 머리·어깨·골반·부츠의 상대 위치와 진행축을 함께 볼 수 있는 구간을 후보로 삼는다. 정면만 보여 앞뒤를 구분할 수 없는 장면에서는 “이 방향에서는 상체의 앞뒤 위치를 확인하기 어려워요”라고 표시한다. 영상만으로 발바닥 압력이나 실제 무게중심을 단정하지 않는다.
- **폴을 든 팔의 높이**는 같은 턴 단계에서 좌우 손이 각 어깨에 비해 얼마나 올라가거나 내려왔는지 측정한다. 길이는 화면상 몸통 길이로 정규화한다. 폴을 짚는 쪽과 반대쪽을 구분해 정상적인 손의 높이 차이를 오판하지 않도록 한다.
- **팔꿈치 굽힘**은 좌우 각각 어깨–팔꿈치–손의 화면상 내각을 180°에서 뺀 값으로 표시한다. 팔을 곧게 펴면 0°에 가깝다.
- **위팔 벌림**은 정면에 가까운 구간에서 몸통의 아래 방향(양 어깨 중점에서 양 골반 중점)과 위팔의 방향(어깨에서 같은 쪽 팔꿈치)이 화면에서 이루는 각도로 측정한다. 팔을 앞으로 뻗은 동작과 옆으로 벌린 동작을 구분하기 어려우면 벌림 코칭을 보류한다.
- **양손 너비**는 화면상 양손 간격을 어깨너비로 나눈 값이다. 몸이 옆으로 돌아 어깨가 겹치는 장면은 비율을 보류한다. 각 지표는 필요한 점이 보이는지 독립적으로 확인하고, 턴 단계별 기준·지속시간과 교정 문구는 경험자가 검토한다.
- 한쪽 무릎이 다른 쪽보다 덜 굽었거나 화면상 각도가 작게 변했다는 사실만으로 오류를 판정하지 않는다. 정면 투영, 가림, 좌우 추적 뒤바뀜, 카메라 움직임이 결론을 바꿀 수 있는 구간을 걸러낸다.

## 검증과 미결정 사항

EPFL의 WebP·JSON은 선택된 프레임의 관절과 화면상 각도 검증에 사용한다. 기존 1,982장의 정답 좌표 분석에서 양쪽 무릎을 측정할 수 있었던 사진은 1,527장이다. 영상 추정 정확도는 별도 측정한다. 연속 MP4에서 사람이 전환 시각과 숏턴 구간을 표시하고, 코칭 문구를 줄 구간과 보류할 구간도 검토한다. 경기 영상의 모든 프레임을 모범 자세로 간주하지 않는다. [EPFL 자료 안내](https://www.epfl.ch/labs/cvlab/data/ski-2dpose-dataset/)

각도 평균 절대 오차(도)와 유효 측정 비율, 숏턴 구간의 시간 겹침 비율, 전환 시각 오차(초), 잘못된 코칭 및 보류 건수를 각각 기록한다. 기준을 정하는 영상과 최종 평가 영상은 주행 단위로 나눈다. 합격 수치와 기준 동작 검토자는 평가 전 합의한다.

스키 경험자가 시범 장면과 교정 문구를 검토할 수 있다. 검토 기록에는 클립·시간대, 턴 단계, 관찰 부위, 기대 결과(교정·유지·판단 보류), 권장 문구와 사유를 남긴다. 실제 승인 장면과 수치 기준은 아직 확정되지 않았다. 미결정 항목에는 지원 파일·길이 한도, 영상 처리 위치와 보관 정책이 있다. 업로드는 사용자가 파일을 선택하는 제품 동작을 뜻하며 서버 저장 여부는 미정이다.
